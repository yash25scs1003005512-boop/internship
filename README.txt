Yash Raj — Internship Website

Publish this folder using GitHub Pages:
1. Create a new public GitHub repository, for example: yash-internship.
2. Upload index.html to the repository root and commit it.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub to publish the site. Its URL will look like:
   https://YOUR-GITHUB-USERNAME.github.io/yash-internship/

Once published, make a QR code that points to that exact public URL.
Do not use a guessed URL before the page is live.
